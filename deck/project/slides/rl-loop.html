RL: learn a policy from rewards, by trying

Agent

follows a policy

Environment

the world it acts in

action

new state + reward

observe → act → receive reward → improve the policy → repeat

No labels, no right answers: only a score for what the agent tried.

Reinforcement learning in one picture. An agent acts in an environment. At each step it observes the state, chooses an action, and gets back a new state and a reward, a single number. The policy is its strategy: state in, action out. Learning means changing the policy so total reward over time goes up. The key contrast with what learners already know: nobody hands the agent the correct action. It finds out by trying and being scored.
