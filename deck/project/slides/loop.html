Chapter 1 · Pip learns by trying

Every move is the same four beats

👀

Look

where am I?

→

🦶

Move

try something

→

⭐

Get stars

+10 goal, +2 coin, −0.1 per step

→

🧠

Remember

that move was good / bad

Repeat 2,000 times. Nobody shows Pip the way.

Pip starts by wandering at random: it knows nothing. Then it practises 2,000 times. Each step is look, move, get stars, remember. In the notebook learners watch the learning curve climb and see the mind map of arrows Pip built for itself.
