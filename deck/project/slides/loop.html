The loop: sample → score → nudge

1 · Sample

8 replies to the same prompt from the LoRA model, temperature 0.9.

6 of 8 earned full reward: exactly 3 bullets, not too long.

2 · Score

A reward function turns each reply into a number.

It sees only what it checks: bullets and word count, not truth or tone.

3 · Nudge

Raise the probability of above-average replies, lower the rest.

Miniature policy: the correct reply goes 0.40 → 0.99.

RL can only promote replies the model already produces. Best-of-N does it at inference time; RL moves it into the weights.

Reference run (pre-run notebooks in reference_runs/).

The intuitive loop behind PPO and friends. Sample several replies, score each, nudge the model toward the higher-scoring ones. In the notebook the LoRA model already produces the good reply most of the time; RL makes it more reliable. The miniature policy has only five candidate replies, so learners can watch every probability move. Stress the limit: RL can't promote a reply the model never produces.
