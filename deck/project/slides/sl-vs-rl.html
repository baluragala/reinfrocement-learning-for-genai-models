Operator demonstrations: 20 drives, 70% of them to the easy coin. Reference run (pre-run notebooks in reference_runs/).

Put supervised learning and RL side by side on the same task. Behaviour cloning copies the most common action in every state the demonstrator visited, so it inherits the demonstrator's habit of taking the easy coin. RL never saw a demonstration and still found the goal, because the reward pointed there. The bottom row is the mapping for the rest of the day: SFT and LoRA are behaviour cloning for text; RL scores the model's own replies.
