Chapter 2 · Gold stars for answers

For a chatbot, someone has to write the stars

def stars(reply):
    score = 1 if has_exactly_3_bullets(reply) else 0
    score -= 0.01 * words_over_40(reply)
    return score

Learners write this 3-line rule. That number is all coaching will ever see.

In the maze the stars were obvious. For a chatbot, someone has to turn 'a good reply' into a number. Learners pick the best of five answers, then score them with this rule, and discover what it can't see: truth, tone, detail.
