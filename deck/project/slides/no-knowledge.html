Section 3 · What RL can't do

RL re-weights what the model already says. A fact it never learned stays at probability zero.

Acme's backpack warranty is in its knowledge base but in no training data. Base guessed, LoRA invented, RL hedged. Nobody knew it.

Preference-based RL changes behaviour, not knowledge. On the miniature policy, a correct reply with reference probability zero stays at zero even when optimised with almost no leash, because it's never sampled, never scored, never reinforced. On the real models, the held-out warranty fact isn't known by any variant. The RL model's change is behavioural: it admits it doesn't know instead of inventing. If you need new facts, use retrieval or put them in the prompt.
