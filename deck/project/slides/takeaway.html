The one thing to remember

Coaching changes WHICH answer a model prefers. It doesn't teach it anything new.

So it's only as good as the comparisons you give it, and only worth it when prompting and fine-tuning can't fix the problem.

Say it slowly. Then the five-chapter recap: stars and hacking; someone writes the stars and a leash limits damage; RLHF and DPO both learn raters' habits; LoRA teaches how, RL teaches which, over-coaching backfires; test for yes-men and scaredy-cats before launch.
