Reinforcement Learning for GenAI Models

What RL changes in a model, what it doesn't, and when it's worth it

Five notebooks · one small open model · three versions of it

Welcome. Last session we evaluated an agent built on a big API model. Today we look underneath: how are models shaped after pretraining, and what does reinforcement learning actually do to a model? One running case, Acme Outfitters again, and one small open model you could run on a laptop. We'll build intuition in toy worlds first, then compare a base model, a LoRA-tuned model and an RL-tuned model on the same prompts. Everything you see was pre-run; we walk through the results rather than train live. Training is intuition only today: no derivations.
